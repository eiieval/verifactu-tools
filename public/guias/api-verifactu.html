API de VeriFactu: cómo elegir proveedor

Si tu empresa desarrolla software de facturación o un ERP, tienes dos caminos: implementar VeriFactu desde cero o integrar una API especializada. Las sociedades estarán obligadas desde el 1 de enero de 2027 y el resto de contribuyentes desde el 1 de julio de 2027, así que el tiempo cuenta.

Qué hace una API de VeriFactu

  • Genera el registro de facturación de alta o anulación a partir de los datos de la factura.
  • Calcula la huella SHA-256 y la encadena con el registro anterior.
  • Devuelve el código QR con la URL de cotejo de la AEAT.
  • Construye el XML y lo envía a la AEAT, a menudo con su propio certificado como colaborador social, para que tus clientes no tengan que gestionar certificados.
  • Ofrece un entorno de pruebas y avisos del estado de cada envío.

La declaración responsable no se delega

Integrar una API no exime a tu software de sus obligaciones. El fabricante del sistema de facturación debe firmar su propia declaración responsable, y el proveedor de la API firma la suya. Las sanciones para fabricantes de sistemas no conformes llegan a 150.000 € por ejercicio, según el artículo 201 bis de la Ley General Tributaria. Antes de elegir, revisa qué cubre exactamente el proveedor.

Criterios para elegir

  • Precio. La mayoría cobra por NIF y mes. Calcula el coste con el número de clientes que tendrás.
  • Entorno de pruebas gratuito, para integrar sin pagar desde el primer día.
  • Cobertura. TicketBAI si tienes clientes en el País Vasco, y factura electrónica B2B y Peppol para las obligaciones de 2027 y 2028.
  • Integración. SDKs para tu lenguaje, webhooks y buena documentación.
  • Seguridad. Certificaciones como ISO 27001 o el Esquema Nacional de Seguridad.

Proveedores

Datos públicos de cada proveedor a 4 de octubre de 2026. Consulta siempre sus condiciones actualizadas.

  • B2Brouter. API para ERP y SaaS con SDKs, webhooks y claves de prueba y producción. Es punto de acceso Peppol y declara certificaciones ISO 27001 y ENS.
  • Verifacti. API REST con empresa de prueba gratuita. Envía a la AEAT con su propio certificado como colaborador social y también cubre TicketBAI.
  • Storecove. Plataforma internacional de facturación electrónica con soporte para VeriFactu.

Si un enlace aparece marcado como "enlace de afiliado", podemos recibir una comisión si contratas a través de él, sin coste para ti. El orden y el contenido de esta guía no dependen de ello.

Antes de integrar

Comprueba tus cálculos con el validador gratuito: huella, encadenamiento de registros y QR, sin enviar datos a ningún servidor. Y repasa los errores más frecuentes de la huella.
